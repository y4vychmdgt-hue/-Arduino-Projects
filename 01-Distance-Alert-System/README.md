# Arduino-Based Distance Alert System

## Project Overview

This is one of my personal Arduino projects, developed
through self-learning and hands-on experimentation.

The project is designed to measure the distance between
an object and an ultrasonic sensor and automatically
activate an alert when the object gets too close.

## How It Works

The ultrasonic sensor continuously measures the
distance between the sensor and nearby objects.

When the measured distance is 20 cm or less,
the Arduino activates:

- A red LED as a visual warning.
- A buzzer as an audible warning.

When the distance is 20 cm or more, the alert
remains inactive.

The measured distance is displayed in real time on a 16×2 LCD screen, allowing users to monitor the distance while the system automatically activates an LED and buzzer when the distance is 20 cm or less.

## Components

- Arduino Board
- HC-SR04 Ultrasonic Sensor
- Red LED
- Buzzer
- Breadboard
- Jumper Wires
- 16×2 LCD Display

## Skills Demonstrated

- Arduino Programming
- Ultrasonic Sensor Integration
- Conditional Programming
- Electronic Circuit Prototyping
- Hardware and Software Integration
