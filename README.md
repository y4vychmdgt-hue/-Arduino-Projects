## Featured Projects

### 1. Distance Alert System

An Arduino-based system that measures the distance between an object and an ultrasonic sensor.

When the distance is 20 cm or less, the system activates a red LED and a buzzer to provide visual and audible warnings.

The measured distance is also displayed on a 16x2 LCD screen.

**[View Project 1](./01-Distance-Alert-System)**

### 2. Smart Temperature-Controlled Fan

An Arduino-based cooling system that automatically adjusts fan operation based on temperature readings from a DHT11 sensor.

The system uses three LED indicators to represent different temperature levels:

- Green: Below 25°C, fan OFF.
- Yellow: 25°C to below 30°C, medium fan speed.
- Red: 30°C and above, maximum fan speed.

**[View Project 2](./02-Smart-Temperature-Controlled-Fan)**
